# Glossaire

| Terme | Définition dans Accordly |
| --- | --- |
| Accord | Ensemble de trois classes de hauteur attendu par le trainer actuel |
| Accord accidenté | Accord dont la fondamentale contient un dièse dans le catalogue actuel |
| Attempt / tentative | Analyse d'un segment audio comparée à l'accord courant |
| Trainer | Parcours qui génère les accords, écoute et valide les réponses |
| Session | Série configurée de 10, 20 ou 50 accords |
| Basic Pitch | Moteur actuel d'estimation de notes à partir de l'audio |
| Classe de hauteur | Nom de note sans octave, par exemple `C#` |
| Seuil RMS | Niveau minimal utilisé pour décider si un segment doit être analysé |
| Historique | Jusqu'à 20 résultats de session stockés dans `localStorage` |
| PWA | Application web installable avec manifeste et service worker ; option de distribution privilégiée mais encore en évaluation pour Accordly |
